- INDEXES

idx in simple terms can be called as config.
EXPLAIN ANALYZE SELECT...
-analyze command explains how much time does postgres took for execution of 
query

** postgres creates an index table which is an internal table of actual table generated through query.
** index table managed by system logs internally. 
** in simple terms, index table is managed using b+ trees(balanced trees)

CREATE INDEX idx_<custom-colum-name> ON <TABLENAME>(<column name>) -this actually stores memory location
CREATE INDEX idx_<custom-colum-name> ON <TABLENAME>(<column name>) INCLUDE(<column name>) -this actually stores the data directly in system logs (disk)
** non key value index -> CREATE INDEX idx_<custom-colum-name> ON <TABLENAME>(<column name>) INCLUDE(<column name>)
** schema table will get locked when indexes are implemented.
